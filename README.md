# Proyecto de Cátedra – Administración de Bases de Datos

## Sistema de Gestión Bibliotecaria

Proyecto académico desarrollado para la asignatura **Administración de Bases de Datos**, utilizando Microsoft SQL Server y Power BI.

## Descripción del proyecto

El proyecto consiste en el diseño e implementación de una base de datos relacional para la gestión de una biblioteca. El sistema permite organizar información relacionada con libros, autores, editoriales, categorías, ejemplares, socios, empleados, préstamos, devoluciones y multas.

Se implementaron diferentes componentes para la administración de la base de datos, incluyendo seguridad mediante usuarios y roles, auditoría, optimización de consultas, índices, respaldos y recuperación de información.

Además, se desarrolló un dashboard en Power BI conectado a SQL Server para visualizar indicadores y analizar la información bibliotecaria mediante gráficos y filtros interactivos.

## Tecnologías utilizadas

- Microsoft SQL Server 2025 Developer.
- SQL Server Management Studio (SSMS).
- Microsoft Power BI.
- Visual Studio Code.
- Git y GitHub.

## Base de datos

**Nombre:** BibliotecaDB

La base de datos está conformada por once tablas relacionadas mediante claves primarias y foráneas, que permiten mantener organizada la información del sistema bibliotecario.


## Propósito

Aplicar los conocimientos de diseño, implementación, administración, seguridad, optimización y análisis de bases de datos mediante el desarrollo de una solución funcional para la gestión bibliotecaria.
